# Contributing to PKIET CGPA Tracker

First off, thank you for considering contributing to the PKIET CGPA Tracker! It's people like you who make this tool great for every student.

## Development Workflow

1. Fork the repository and create your branch from `main`.
2. Install dependencies using `npm install`.
3. If you've added code that should be tested, add tests!
4. Ensure the app bundles correctly with `npx expo start -c`.
5. Issue a pull request with a clear description of your changes.

## Coding Guidelines

- Use functional components and React Hooks.
- Keep components small and focused.
- All database operations should go through the `database/services` layer.
- Use `Ionicons` for consistency across the UI.
- Maintain the "Midnight Sapphire" theme (#232867).

## Reporting Bugs

- Use the GitHub issue tracker to report bugs.
- Describe the expected behavior and actual behavior.
- Include screenshots and device information (OS version, device model).
